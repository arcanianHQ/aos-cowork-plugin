# data-template/

The **canonical layout** of an AOS data folder — the granted folder that is the
system of record. `aos-onboard` copies this structure into the client's granted
folder on first run.

Do **not** store real client data here — this is a template, versioned with the
plugin. Real data lives only in the client's granted folder.

Full spec: `../docs/data-folder-spec.md`.
