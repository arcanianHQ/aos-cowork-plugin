# Reference — pre-delivery checklist

> Run end to end before a Hungarian artifact is declared done. Faithfully ported from the Arcanian Stílusútmutató "Ellenőrzőlista Publikálás Előtt". Cross-references: error classes → `anti-patterns.md`; stuck words / calques → `calques.md`; rhythm / voice → `idioms-and-voice.md`; letter rules → `letter-register.md`.

## Composition principle (highest level)

- [ ] **Composed in Hungarian, not translated from English?** (read-aloud test, idiom check, clause-structure check)
- [ ] If a passage stumbled on the read-aloud test, was it rewritten **from a Hungarian thought** — not patched word by word?
- [ ] **After rewriting, was the read-aloud test re-run on your OWN rewrite?** A nativeness pass can introduce a fresh calque (abstract noun + motion verb, a forced purpose-clause).

## Language quality

- [ ] No "meg lehet + főnévi igenév" construction? (`anti-patterns.md` §1)
- [ ] No nominalisation-stacking? (§2)
- [ ] No English-word-order sentence? (§3)
- [ ] No unnecessary "amely/amelyek"? (§7)
- [ ] No translation-flavoured expressions? (§6)
- [ ] No stuck English word (bottleneck, lever, power, subscription, framework, deck, friction, etc.)? (`calques.md`)
- [ ] No verb invented from English (kaszkádol, targetál, diszruptál)? (§9)
- [ ] **No HU suffix on an English noun (compoundolódnak, frictionök, onboardingotok, subscription-je, deploy-olom)?** (§12)
- [ ] **No consulting-deck phrase (kézzelfoghatóvá, differenciálást építeni, minőségi kapu, DNS-e kódolt formában)?** (§13)
- [ ] Conditional-mood suffixes correct (-na/-ne vs -ná/-né)? (§10)
- [ ] **"agent" in writing (not "ágens")?** (`calques.md` §8b)
- [ ] **"ülés" → "egyeztetés" (except institutional)?** (`calques.md` §8c)
- [ ] **Web/server context: "kint van" → "fent van" / "szerepel" / "élesben van"?** ("kint" only for physical outdoor space — `calques.md` §6a-bis)
- [ ] **No calqued English idiom ("ez a ti hívásotok", "különbséget hozni", "a nap végén")?** (`calques.md` §6d)
- [ ] **No calqued word-sense ("oldal" = side, "élő" = live access, "olvasás" = reading data)?** (`calques.md` §6e)
- [ ] **No PPC-domain stuck word (ad copy, landing page, read-only, trial, review, account, margin)?** (`calques.md` §8e)
- [ ] **a/az article correct before vowel-initial words — especially around English words and acronyms ("az ICP", "az üzleti…")?**
- [ ] **No written-out "BLUF" label?** (the conclusion-first principle stays — as sentence content, not as a label — §13b)
- [ ] **Max 1 negation-affirmation ("nem X, hanem Y") — and only for a real contrast?** (§11)
- [ ] **No AI-marketing opener? (A mai gyors tempójú világban, Nem véletlen hogy, Képzeld el, Fontos megjegyezni, Valódi áttörés, rhetorical-question-then-answer, synonym triplet)?** (§14)
- [ ] **Read aloud — no LinkedIn-post / SEO-article feel?**
- [ ] Short-long rhythm alternates? (`idioms-and-voice.md`)
- [ ] One thought = one sentence?
- [ ] At least one HU-native idiom or particle present? (`idioms-and-voice.md`)

## Letter-specific (if the artifact is a letter — `letter-register.md`)

- [ ] **Definite article before time spans ("A következő négy hét…", not "Következő négy hét…")?**
- [ ] **A connector phrase in the opening (ahogyan beszéltük / ahogy ígértem / ahogy hétfőn megbeszéltük)?**
- [ ] **No meta-pitch about the document itself ("csak a fő pontok — ha mélyebbre mennél, szólj")?**
- [ ] **Category headers in prose, not deck-style (no "+" or "/" construction)?**
- [ ] **No "+" as a connector inside a sentence either? (only stays for a mathematical context)**
- [ ] **No "×" as a connector either (matrix/spreadsheet tell — even stronger than "+")?**
- [ ] **No forced `Hogy …, …` purpose-clause bridge (meta-pitch in disguise)?** (`letter-register.md` Rule 3)
- [ ] **Closing formula with a comma ("Üdv,"), not a colon?**
- [ ] **No reference to an internal draft iteration ("a tegnap körvonalazott", "a v3-at átdolgoztam")?**
- [ ] **No internal disambiguation / internal reasoning leaked into the body?**

## Arcanian voice (`idioms-and-voice.md`)

- [ ] No "őszintén" / "nem felülről" / "segítek"?
- [ ] Active verbs (rátapintunk, feltérképezzük, végigvezetjük)?
- [ ] A self-diagnostic beat present?
- [ ] Partnership language ("együtt" forms)?
- [ ] Map → System → Change touched (even implicitly)?

## Post-specific (if the artifact is a post)

- [ ] Hook — are the first 2 lines strong enough?
- [ ] Shareability — would they share it for their OWN reason?
- [ ] Close — a question or reflection (not advice)?

## Fidelity

- [ ] **No claim added, dropped or altered?** A nativeness pass changes form, never facts.
- [ ] `brand/VOICE.md` register / banned words / address form respected where it exists?
