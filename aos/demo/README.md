# Demo data — "Lumen Audio"

A **fictional** sample client, bundled so AOS can be tried without real client
data (AOS-741).

**Lumen Audio** is a made-up direct-to-consumer headphone brand — one product,
the *Lumen One*. This folder holds its `inbox/` material: a positioning brief
and a discovery-call transcript — enough to exercise the full pipeline
(`aos-catalogue` → `aos-build-brand-system` → the 9-file Client Intelligence
Profile).

## Using it

This is **not** a real client folder and is never installed as one. To try AOS
on the demo client: onboard a fresh granted folder with `aos-onboard`, then copy
`demo/inbox/` into that folder's `inbox/` zone and run `aos-catalogue`.

Everything here is fictional — safe to read, copy, and delete.
