# Content catalogue

Index of every content piece in `content/`, organised **by series**. Generated by
the **`aos-catalogue`** skill — re-run to refresh. New pieces and series are added
by `aos-draft-content`.

A **series** = one storytelling-framework run (one framework → ~10–11 pieces). A
series can span multiple platforms — see `content/README.md` and
`docs/content-framework.md`.
