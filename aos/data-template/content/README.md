# content/ — produced content pieces

The actual content the pipeline drafts — reference posts, blog posts, linkbait —
produced by the `aos-draft-content` skill. One subfolder per business unit
(`content/<bu>/`).

Distinct from:
- `content-system/` — the per-BU content *foundation* (pillars, messaging, products, distribution)
- `deliverables/` — reports, decks

`content/` holds the publishable pieces themselves.

`CATALOGUE.md` — the index of every piece (built / refreshed by the `aos-catalogue` skill).
