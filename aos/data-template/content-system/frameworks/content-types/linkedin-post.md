# Content type — LinkedIn post

> **What it is.** A single short-form post in a LinkedIn feed. The unit of a
> single-platform Hero's Journey or Before-After-Bridge series. Goal: stop the
> scroll, deliver one idea, earn a reaction or a profile visit.

## Platform constraints

| Constraint | Value |
|---|---|
| Length | 120–280 words (≈900–1700 chars). The "see more" fold is ~3 lines — the hook must land above it. |
| Media | Optional single image or document carousel. Text-only posts are fully valid. |
| Tone register | Peer-professional. First person. Confident, not corporate. One idea per post. |
| Links | In-body links suppress reach — put the link in the first comment, not the post body. |
| Formatting | Short paragraphs (1–2 sentences). Line breaks are structural. No hashtag walls — 3–5 max, at the end. |

## Supported structures (Level 3)

- **`hook-insight-cta`** *(default)* — hook → context → insight → CTA. The
  general-purpose skeleton; fits most beats.
- **`story-lesson`** — scene → tension → turn → lesson → bridge. For narrative
  beats (a real moment, a transformation) — Hero's Journey beats 1, 7, 10;
  Before-After-Bridge beats 1, 5.

A beat whose narrative job is "tell a moment" → `story-lesson`. A beat whose job is
"make a point" → `hook-insight-cta`.

## Distribution note

- Ships to: the brand's LinkedIn page and/or the founder's personal profile
  (personal profiles out-reach company pages — prefer the founder's voice).
- Cadence in a series: 2–3 posts per week, so an 11-beat series runs ~4–6 weeks.
- The conversion link lives in the first comment; the post body stays link-free.
