# Content type — Email

> **What it is.** A single email to the brand's list. In a series, the email
> carries the **nurture beats** — the integration / first-step moments where the
> audience is moving from interest toward action. Goal: a direct, one-to-one
> moment that a feed post cannot deliver.

## Platform constraints

| Constraint | Value |
|---|---|
| Length | 90–250 words in the body. An email is read in seconds — one idea, one ask. |
| Subject line | 30–55 chars. Curiosity or value, never clickbait. The subject *is* the hook. |
| Media | Mostly text. One image at most. Plain-text-feeling emails out-perform heavy templates. |
| Tone register | One-to-one, warm, direct. As if written to a single named reader. |
| Links | One primary link / CTA. A second link only if genuinely needed. |
| Formatting | Short paragraphs, generous white space. A single bolded line for the ask is fine. |

## Supported structures (Level 3)

- **`one-thing`** *(default)* — subject → one-line context → the one thing →
  single CTA → sign-off. The whole email serves one idea and one ask.

## Distribution note

- Ships to: the brand's email list (newsletter or sequence).
- In a series: typically 1 email beat — the "first step" / integration moment
  (Hero's Journey beat 9, Before-After-Bridge beat 9). Email is where a warm
  audience is asked to *do* something, after the feed beats built the desire.
- Cadence: send the email beat in step with the surrounding feed beats so the
  series reads as one arc across channels.
