# Content type — Blog post

> **What it is.** A long-form educational piece on the brand's own blog. In a
> series, the blog post carries the **deep beats** — the ones that need room:
> proof, framework, the honest hard part. Goal: SEO + topical authority + a
> durable asset the series links into.

## Platform constraints

| Constraint | Value |
|---|---|
| Length | 1200–2500 words. Below ~1000 it does not earn the long-form slot; above ~2500 finish-rate drops. |
| Media | Inline images expected — diagrams, photos, before/after. Image markers for the photo team. |
| Tone register | Mentor-practitioner. "We've done this many times, here's what we noticed." Not lecture. |
| Links | 2+ internal links (topic graph) + 1+ external authoritative source. |
| Formatting | H1 = title, H2 section spine, H3 within. One primary keyword + 3–5 secondary. |

## Supported structures (Level 3)

- **`problem-framework-proof`** *(default)* — problem framing → why now → the
  framework → applied examples → common mistakes → next step. The own-blog
  authority skeleton.

## Distribution note

- Ships to: the brand's own blog. Optionally cross-posted to LinkedIn (tighten the
  hook, trim — see `aos-draft-content` Integration notes).
- In a series: 1–2 blog beats per series run; they are the assets the LinkedIn
  beats link into (link in first comment).
- Cadence: a blog beat takes longer to produce — schedule it ahead of the LinkedIn
  beats that reference it.
